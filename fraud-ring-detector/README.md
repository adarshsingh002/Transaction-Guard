# Fraud Ring Detector

This project implements a two-layer architecture for detecting fraud rings. Layer 1 focuses on analyzing individual transactions and accounts to identify anomalous behaviors. Layer 2 leverages network graphs and clustering algorithms to uncover coordinated fraudulent activities among groups of accounts.

## Build Order

1. data gen
2. layer1 rules
3. layer1 ML
4. layer2 graph
5. layer2 scoring
6. fusion
7. audit
8. dashboard
